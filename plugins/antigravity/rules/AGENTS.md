# MetaSkill Rules (Antigravity)

- Follow the Before · During · After cycle: propose a short contract in `SPEC.md` (`## Contract`) before editing, verify each step, and deliver `.agents/evidence/report.md` before saying "done".
- Start in `read-only` mode when inspecting or advising unless editing is authorized.
- Save Antigravity visual/browser artifacts (screenshots, recordings) in `preview/` and reference them in `SPEC.md` with `file: preview/<name>.png` so `mtsk verify` checks them automatically.
